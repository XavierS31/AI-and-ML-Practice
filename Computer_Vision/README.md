# COMPUTER VISION Coding

This Folder holds the Computer Vision Practice and small projects on datasets using PyTorch.

## [Softmax and Two-Layer Network](Softmax_and_Two_Layer_Net/)

Two PyTorch image classifiers with Python scripts and Jupyter notebooks. The softmax classifier uses one linear layer, and the two-layer network adds a hidden layer with ReLU.

## [ViT Depth Minimal](ViT_Depth_Minimal/)

A minimal Vision Transformer for CIFAR-10 that compares two and four encoder blocks. The project includes the executed notebook, Python script, and report with learning curves and misclassified images.
